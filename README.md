## QR Code Generator

# What is this?
This project focuses on creting a Windows based GUI to generate QR codes.
It is still in early development, for now this prototype has the following features:

- Prompt user for desired path to save code with GUI
- Prompt user a name for the QR code

# Long term goals
It is a personal goal to provide an application that does not require needless registrations to unknow pages that you will only use once.

This application will have a stable Windows release for people to use free of charge soon. 
Stay tuned!!!
